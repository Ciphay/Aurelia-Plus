# catalog

`catalog.json` is generated by `python -m tools.catalog.extract --dll steamclient64.dll --lsteamclient lsteamclient.so --out catalog/catalog.json`.

Coverage on 14/Nov/2026 (reference DLL from 12/Nov): 203 interface versions, 177 with complete slots,
24 without slots (name only), 5500 resolved slots. The earlier reverse engineering counted 235 vtables and 7120 slots; the
difference is the client's internal interfaces, which do not appear in `CreateInterface` and which we will not reimplement.
